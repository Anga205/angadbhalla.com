# Angad Bhalla - Software Engineer Portfolio

## About

This is my personal portfolio website!

## Site Structure

- **Home** (`/`): Main portfolio and projects showcase
- **Projects** (`/projects`): Collection of technical projects
- **Resume** (`/resume`): Professional background and experience
- **Contact** (`/contact`): Contact form and information

## Built With

- **Framework**: Astro
- **Styling**: Tailwind CSS
- **Components**: React, Vue, Svelte, and other framework components
- **Deployment**: Netlify

## Development

To explore this portfolio locally:

```sh
bun install
bun dev
```

The site is built with Astro and optimized for technical audiences interested in systems programming and infrastructure development.
